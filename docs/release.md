# Дистрибутивы Windows

Просьба «сделай демо» означает **собрать установщик нужной версии** и отдать
ссылку на него. Команда выполняется из корня репозитория в PowerShell:

```powershell
./tools/build_demo.ps1 -Version 0.1.0
```

Без `-Version` используется `application/config/version` из `project.godot`.
Формат версии: `major.minor.patch`, компоненты 0–65535. Номер передаётся
в меню игры, свойства игрового exe, установщик, его имя и манифест сборки.
Параметр меняет только копию проекта. Чтобы изменить версию по умолчанию,
обновите `config/version` в исходном `project.godot`.

Другие варианты:

```powershell
./tools/build_demo.ps1 -Version 0.1.1 -Portable
./tools/build_release.ps1 -Edition Full -Version 0.1.0
```

`-Portable` дополнительно создаёт ZIP для запуска без установки.
В полной версии остаются обычные игровые режимы; демо использует экспортную
фичу `demo` и собственный профиль сохранений.

## Требования

Windows x64, PowerShell 5.1 или 7, Git, Godot и Windows release-шаблон
**той же версии**, что и движок. Движок берётся из `-GodotPath`, `GODOT`,
корня проекта (`Godot_v*_console.exe`) или PATH (`godot`, `godot4`).

Для установщика нужен [Inno Setup 6](https://jrsoftware.org/isdl.php).
Путь к `ISCC.exe`: параметр `-IsccPath`, переменная `ISCC`, локальный
`build/toolchain/inno/ISCC.exe`, стандартная установка или PATH.
Пайплайн сам ничего не скачивает и не устанавливает.

```powershell
./tools/build_demo.ps1 -Version 0.1.1 -IsccPath 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe'
```

В проверенном окружении: Godot 4.7.1, Inno Setup 6.7.3. При смене движка
или компилятора необходимо заново проверить установку и запуск.

## Что делает пайплайн

1. Проверяет версию, зависимости, наличие интро и отсутствие готового релиза
   с тем же номером. Существующий дистрибутив не перезаписывается.
2. Копирует игровые каталоги в `build/release-work/<id>/project`, переносит
   кэш импорта и выполняет импорт. В копии крупный арт переводится в WebP
   с качеством 90% без уменьшения разрешений. Список каталогов и качество —
   `tools/installer/texture_profile.json`; UI, шрифты, музыка и видео не меняются.
   Исходный проект, его настройки импорта и редактор не меняются.
   Импорт обязателен: прежний `-SkipImport` больше не поддерживается.
3. Экспортирует release-пресет с `embed_pck=false`: движок остаётся в exe,
   игровой контент — в одноимённом PCK. Проверяет наличие PCK, версию PE
   и ограничение exe **150 МиБ**.
4. Запускает **экспортированную игру**, а не редактор, с ключом
   `--headless -- --verify-distribution <версия> <Demo|Full>`.
   Встроенный `scripts/distribution_check.gd` проверяет версию и редакцию, интро,
   карту миссии, меню, вход в кампанию и ограничения кнопок демо.
   Проверка использует временный APPDATA, поэтому не трогает сейвы игрока.
   `HOTG_DISTRIBUTION_CHECK_PROFILE` должен указывать на тот же каталог:
   без этого подтверждения изоляции проверка отказывается запускать кампанию.
   Ошибки Godot в логах также останавливают сборку даже при коде выхода 0.
5. Записывает коммит, наличие незакоммиченных изменений, UTC-время,
   версии инструментов, размеры и SHA256 файлов в `game/build-info.json`.
6. Компилирует русский установщик с [LZMA2](https://jrsoftware.org/ishelp/topic_setup_compression.htm).
   Он устанавливается для текущего пользователя без прав администратора,
   создаёт ярлык в «Пуск», по желанию — на рабочем столе, и поддерживает удаление.
   Постоянный AppId раздельный для Demo и Full: следующая версия обновляет
   свою редакцию. Сохранения лежат вне установки и при удалении остаются.
7. Проверяет версию установщика и ограничение **300 МиБ**, по запросу
   создаёт ZIP, записывает SHA256SUMS.txt и публикует результат в `build/releases/`.
   Неудачная сборка остаётся в `build/release-work/` вместе с логами.

Ограничения размера — предохранитель от случайного раздувания. При обоснованном
росте контента их меняют в `build_release.ps1` после проверки состава пакета.
Разделение exe/PCK само по себе не уменьшает контент; размер скачивания
снижают профиль арта и сжатие установщиком. WebP 90% — сжатие с потерями,
поэтому оно применяется только к копии для выпуска. Музыка, интро,
разрешения изображений и исходный арт сохраняются.

## Результат

```text
build/releases/demo/0.1.0/
  HeroesOfTheGalaxyDemo-0.1.0-windows-x64-setup.exe  <- отдавать игрокам
  SHA256SUMS.txt
  game/
    HeroesOfTheGalaxyDemo.exe
    HeroesOfTheGalaxyDemo.pck
    ПРОЧТИ МЕНЯ.txt
    build-info.json
  logs/
```

ZIP появляется рядом с установщиком только при `-Portable`. Каталог `game/`
можно запускать напрямую, но **exe нельзя передавать без PCK**.
Установщик и игра пока не подписаны цифровым сертификатом.

Проверка установки перед распространением: установить в тестовый каталог,
запустить игру и первую миссию, повторно установить поверх той же версии,
затем удалить через штатный деинсталлятор. Автоматическая проверка пайплайна
проверяет экспортированную игру, но не устанавливает её в систему сборщика.

Старые `build_game.sh` / `build_game.cmd` оставлены для простого экспорта
Windows Full / Web. Для дистрибутива с версией используйте команды выше.
