# Android: управление и сборка

Игра работает в альбомной ориентации. Для Android используется логическое
разрешение 1600×900; настольная версия сохраняет 1920×1080. Android APK
содержит только `arm64-v8a` и подписывается локальным отладочным ключом.

| Экран | Управление пальцем |
|---|---|
| Карта | Касание свободной клетки строит маршрут. Повторное касание той же клетки запускает перелёт. Свайп перемещает камеру, щипок меняет масштаб. Удержание на флоте открывает его состав. |
| Бой | Первое касание подсвечивает гекс и показывает доступное действие; второе касание того же гекса подтверждает манёвр, атаку или цель протокола. Кнопки в нижней полосе управляют залпом, протоколами, автобоем и завершением хода. |
| Планета | Касание здания открывает его карточку. Строительство, найм и обмен флотами доступны через кнопки и карточки. |
| Все экраны | Системная кнопка или жест «Назад» закрывает вложенное окно либо открывает меню настроек и сохранения. |

Автоматическое преобразование касаний в мышь отключено: оно давало бы двойное
срабатывание маршрута или атаки. Элементы `Control` получают касания напрямую;
ввод на карте и поле боя обрабатывает `InputEventScreenTouch` и
`InputEventScreenDrag`. Справка доступна в главном меню.

Для экспорта нужны Godot 4.7.1, JDK 21, Android SDK с Platform Tools и
Build Tools 36, а также шаблоны экспорта Godot. В общей папке проекта лежит
локальная копия SDK `build/android-sdk` и шаблонов
`build/android-export-templates/4.7.1.stable`. Папка `build` исключена из Git.

Команда из PowerShell проверяет SDK, выбирает общий SDK из `build/android-sdk`,
обновляет путь в настройках Godot, при необходимости устанавливает шаблоны
экспорта для текущего пользователя и собирает APK:

```powershell
./tools/build_android.ps1
```

Из `cmd.exe` её можно вызвать как
`powershell -ExecutionPolicy Bypass -File tools\build_android.ps1`. Если SDK
лежит в другом каталоге, передайте `-SdkPath`; JDK можно указать через
`-JavaPath`. При уже настроенном редакторе можно вызвать Godot напрямую:

```powershell
./Godot_v4.7.1-stable_win64_console.exe --headless --path . --export-debug Android build/android/HeroesOfTheGalaxy-0.12.0-debug.apk
```

Сенсорную логику без устройства проверяет
`tools/test_android_controls.gd`. APK является тестовой сборкой для установки
на устройство. Для публикации потребуется отдельный релизный ключ и проверка
управления, читаемости интерфейса и производительности на телефоне.
