# Инструменты: снимки экрана, отладочные прогоны, генерация плейсхолдеров

Из `AGENTS.md` сюда ушла вторая половина раздела 1. Список тестов и команда
их запуска остались в `AGENTS.md` — здесь всё остальное из `tools/`.

---

Отладочные скриншоты (сохраняют PNG в `user://`):

```bash
./Godot_v4.7.1-stable_win64_console.exe --path . res://tools/MapShot.tscn -- map.png 8 8 1.0 1001
```

`tools/BattleShot.tscn` — то же самое для тактического боя; второй аргумент
`bandit` ставит против землян флот марсианских бандитов.

`tools/comet_shot.gd` — предпросмотр декораций дальнего космоса (комета с
эффектами и далёкая планета) в отдельном SubViewport, без запуска карты:

```bash
./Godot_v4.7.1-stable_win64.exe --path . --script res://tools/comet_shot.gd
```

`tools/MapEdgeShot.tscn` — снимок настоящей карты, прокрученной в дальний угол:
им проверяется, что поле упирается в правую панель и верхнюю полосу, а не
уезжает под них. Второй аргумент `comet` вместо этого наводит камеру на комету.

```bash
./Godot_v4.7.1-stable_win64.exe --path . res://tools/MapEdgeShot.tscn -- res://map_edge.png
```

`tools/debug_bandit_turns.gd` — не тест, а прогон 40 солов за ИИ марсианских бандитов с печатью
казны, стройки, найма и перемещений главаря. Запускать при правке порогов в
`bandit_ai.gd`.

`tools/debug_map_objects.gd` — сводка раскладки карты: сколько объектов и
стражей какого вида реально встало, где стоят стражи с наградой.

**Диагноз баланса и что с ним делать — `data/balance_plan.md`.** Там же
оговорка про то, почему по одному прогону измерителя судить нельзя.

`tools/balance_sim.gd` — балансовый измеритель: потолок опыта на карте, дуэль
фракций ранг-в-ранг, зависимость «перевес по силе → реальный исход», прогон
кампании на 120 солов и финальное столкновение. Бои считаются НАСТОЯЩИМ
движком боя в режиме быстрого расчёта. Запускать после любой правки статов,
цен, недельного прироста или порогов ИИ.

Плейсхолдер-спрайты марсианских бандитов (корабли, здания, портрет главаря) генерируются
скриптом, а не рисуются руками — заменять файлы можно, не трогая код:

```bash
python tools/make_bandit_placeholders.py
```

## Сборка игры

```bash
sh tools/build_game.sh                  # Windows -> build/full/HeroesOfTheGalaxy.exe
sh tools/build_game.sh Web              # веб      -> build/web/index.html
sh tools/build_game.sh Web --no-intro   # можно и без ролика
```

Из-под cmd, где `sh` нет, то же самое делает `tools\build_game.cmd`
(`tools\build_game.cmd --no-intro`, `tools\build_game.cmd Web`).

Пресеты лежат в `export_presets.cfg` (`Windows Full` и `Web`), вывод — в
`build/` (не в гите). Windows-сборка состоит из небольшого exe и отдельного PCK,
`tools/*` в сборку не попадает. Нужны установленные шаблоны экспорта той же
версии, что и движок (в редакторе: Проект > Установить шаблоны экспорта).

**Интро-ролик.** `video/intro.ogv` — Theora, играется `VideoStreamPlayer`
в `scripts/intro_video_player.gd` и хранится в репозитории. Скрипт сборки
проверяет его наличие, чтобы случайно не выпустить версию без синематика;
`--no-intro` разрешает такую сборку явно. В экспорт ролик попадает как обычный
ресурс (`export_filter="all_resources"`), а Windows-пресет дополнительно
называет его в `include_filter`. Theora проверена и в одиночном (без потоков)
веб-экспорте — играет.

Готовой сборке ролик можно подложить и снаружи: файл `intro.ogv` рядом с
exe (или в профиле игрока, `user://intro.ogv`) игра найдёт сама, если внутри
сборки ролика нет. Внешний файл открывается через `VideoStreamTheora.file` —
`ResourceLoader` такие пути не читает.

Ключи запуска игры: `--intro` показывает ролик и на "Случайной карте",
`--no-intro` не показывает вовсе. Те же решения можно зашить в отдельный
пресет тегами фич `intro` / `no_intro` в `custom_features`.

## Отдельное демо Windows

**Запрос «собрать демо» означает выпуск дистрибутива**, а не голого exe.
Полный пайплайн, требования и формат результата — [release.md](release.md).

```powershell
./tools/build_demo.ps1                 # версия из project.godot
./tools/build_demo.ps1 -Version 0.1.1  # нужная версия установщика и игры
```

Результат: `build/releases/demo/<версия>/HeroesOfTheGalaxyDemo-<версия>-windows-x64-setup.exe`.
Ролик обязателен. Игра состоит из exe и PCK, установщик сжимает оба файла.
Рядом остаются распакованная игра, логи и контрольные суммы.

Тег `demo` закрывает случайную партию, LAN, редакторы и загрузку сохранений
других режимов. Профиль `%APPDATA%/HeroesOfTheGalaxyDemo` отделён от полной
игры. Для проверки ограничений до экспорта: `-- --demo`.
`test_demo_edition.gd` сам запускает дочерний процесс с этим флагом, а
`test_demo_balance.gd` проверяет экономику и обязательные бои миссии.
