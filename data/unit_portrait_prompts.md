# Запросы для портретов техники

Файл описывает готовые промпты для портретов кораблей в очереди хода тактического боя. Каждый блок самодостаточный: его можно копировать целиком без дополнительных инструкций.

Основной формат: **1:1, 1024x1024**. Для версии 2:3 оставлять корабль в центральном квадрате и расширять только фон сверху и снизу, чтобы иконка не теряла читаемость в узкой плашке.
