# Четыре рубежа

Текущая сетевая карта: `four_corners_adventure_v1.tres` — полный снимок обычной
карты 64×64 с биомами, объектами, охраной и наградами. Столицы: (6, 6),
(57, 57), (57, 6), (6, 57). На каждый старт приходится шесть производств.

Сид сборки: 220926. Файл загружается целиком, поэтому обновление генератора
не меняет существующую раскладку. Для намеренной пересборки:

```powershell
./Godot_v4.7.1-stable_win64_console.exe --headless --path . --script res://tools/generate_lan_adventure_map.gd
```

`four_corners_v1.json` — прежняя раскладка упрощённого прототипа; в сетевом
лобби она больше не используется.
