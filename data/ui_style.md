# Интерфейс игры

Общая тема: `assets/ui/game_theme.tres`, подключена в `project.godot` для всех сцен и динамических окон.
Источник палитры и фабрики стилей: `scripts/ui_style.gd`.

- Шрифт: первый вариант из сравнения, Segoe UI Variable Display. На системах без него используются Segoe UI, Noto Sans или Arial; проприетарный шрифт Windows в репозиторий не включён.
- Графитовые непрозрачные окна, светлый основной текст, серые пояснения. Золото обозначает заголовки и активные действия, бирюзовый цвет — информацию и фокус. Цвета противника, школ протоколов и опасных действий сохраняют свой смысл.
- Радиус поверхности — 4 пикселя, рамка — 1 пиксель. Внутренние строки используют разделители, без дополнительных объёмных подложек.
- Все состояния кнопки имеют одинаковые отступы и толщину рамки, чтобы наведение и нажатие не сдвигали содержимое.
- Новые окна наследуют тему проекта. Для особых поверхностей используйте `surface()`, для строк — `inset()`, для кнопок с локальными переопределениями — `apply_button()`.
- Отступы внешних контейнеров задаёт вёрстка окна; тема обычного PanelContainer не добавляет второй комплект отступов.

После изменения фабрики тему нужно пересобрать:

```powershell
.\Godot_v4.7.1-stable_win64.exe --headless --path . --script res://tools/build_ui_theme.gd
```

Съёмка настоящего интерфейса:

```powershell
.\Godot_v4.7.1-stable_win64.exe --path . --windowed res://tools/UiShot.tscn -- settings tmp/ui_settings.png
```

Режимы: `menu`, `settings`, `map`, `battle`, `planet`, `construction`, `garrison`, `exchange`, `reward`, `academy`, `level`, `results`, `preview`, `protocols`.
Герой для окон прокачки создаётся отдельно и не записывается в сохранение.
