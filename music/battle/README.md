# Темы тактического боя

Сюда кладутся mp3-треки для музыки тактического боя (`tactical_battle.gd`).

- Любое количество файлов, любые имена, расширение `.mp3`.
- Файлы подхватываются автоматически — `tactical_battle.gd:_start_music` при
  старте боя сканирует папку и перемешивает треки. Они проигрываются по одному
  без повторов, после последнего очередь перемешивается заново; ничего никуда
  регистрировать не нужно.
- Пустая папка не ломает бой — просто нет музыки.
