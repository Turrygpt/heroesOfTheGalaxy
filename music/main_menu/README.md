# Темы главного меню

Сюда кладутся mp3-треки для музыки главного меню (`MainMenu.tscn`).

- Любое количество файлов, любые имена, расширение `.mp3`.
- Файл подхватывается автоматически — `main_menu.gd:_start_music` при входе
  в меню сканирует папку и берёт случайный трек, ничего никуда не
  регистрировать не нужно.
- Пустая папка не ломает меню — просто нет музыки.
