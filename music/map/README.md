# Темы глобальной карты

Сюда кладутся mp3-треки для музыки глобальной карты (`space_strategy_map.gd`).

- Любое количество файлов, любые имена, расширение `.mp3`.
- Файл подхватывается автоматически — `space_strategy_map.gd:_start_music` при
  входе на карту сканирует папку и берёт случайный трек, ничего никуда не
  регистрировать не нужно.
- Пустая папка не ломает карту — просто нет музыки.
