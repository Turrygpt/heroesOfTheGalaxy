# Спутники Сатурна для кампании

Прозрачные игровые иконки крупных лун Сатурна: Титан, Энцелад, Рея и Диона. Они используют общий ракурс и размер кадра для планетных маркеров стратегической карты. `assets/space/far_planets/saturn_parallax.png` — отдельная планета с кольцами на чёрном фоне для дальнего параллакса.
