# Пиратские станции миссии 2

Четыре отдельные иконки станций-кланов для карты, где они занимают роль планет. Силуэт и оснащение нарастают по кланам: захваченный перевалочный узел, добывающий комплекс, тяжёлая верфь и укреплённая пиратская цитадель.

- `pirate_clan_1.png` … `pirate_clan_4.png` — отдельные станции с прозрачным окружением.
- `pirate_stations_contact_sheet.png` — лист просмотра вариантов.

Пока это арт-ресурсы; игровые точки карты ими ещё не заменены.
