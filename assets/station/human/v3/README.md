# Орбитальная станция: третья версия

Новый набор создаётся встроенным image_gen. Исходные PNG с альфой сохраняются
без изменения; экран использует AtlasTexture для исключения прозрачных полей.
Промпты и происхождение изображений записаны в prompts.json.

## Состав

- Командный центр: 4 уровня.
- Оборонительный отсек: 3 уровня.
- Ангары истребителей, штурмовиков, корветов, фрегатов, эсминцев: по 2 уровня.
- Научный комплекс: 4 уровня.
- Офицерский клуб, торговый терминал, тяжёлая верфь: по 1 уровню.
- Герметичный переход между отсеками.

Вид: белая керамическая броня, графитовые панели, небольшие оранжевые метки,
голубая подсветка; единое освещение слева сверху и ортографическая камера.
Стартовая база состоит только из центра и ангара. Большого каркаса нет.
Переходы появляются вместе с отсеками. Ветки небольших и тяжёлых верфей
продолжают существующую застройку, службы располагаются за командным центром.

Раскладка и масштаб: scripts/saturn_station_screen.gd, словарь MODULES.
Автоматическое вписывание учитывает только построенные здания.
Клики проверяются по альфе и не задевают прозрачные углы соседних спрайтов.

Снимки игрового экрана: tools/saturn_station_shot.gd, флаг --full показывает
все здания максимального уровня. Использовать отдельный тестовый профиль.
