# Арт орбитальной станции Земли

Архивная версия. Игровой экран переведён на полностью перегенерированный
набор `../v3/`; каркас и модули этой папки больше не используются станцией.

Панорама и набор модулей для прототипа экрана станции миссии 2.

- `master.png` — собранная концепция станции максимального уровня.
- `chassis.png` — концепция центрального каркаса без модулей.
- `sources/` — исходные генерации по типу здания и уровню.
- `references/` — пользовательские концепты станции для сверки формы и материалов.
- `layout.json` — перечень зданий, лимиты уровней и зависимости по уровням. Ветки повторяют условия земного города: производственные доки открываются последовательно, поздние требуют форта и предыдущей верфи.

Ключи зданий оставлены совместимыми с `HumanPlanetScreen`: `townhall`, `fort`, `fighter_yard`, `gunship_yard`, `corvette_yard`, `frigate_yard`, `destroyer_yard`, `mage_guild`, `tavern`, `marketplace`, `bank`. В каталоге также зарезервирован `cruiser_yard` для награды четвёртого пиратского клана второй миссии.

Модули подключены к `scripts/saturn_station_screen.gd`: каркас, замена построек по уровням, отдельный командный центр и тяжёлая верфь VI ранга. Банковский модуль остаётся резервным: в общем каталоге города такого здания пока нет. У некоторых исходников остаются мягкие альфа-ореолы; финальная художественная доводка стыков возможна отдельно от игровой логики.
