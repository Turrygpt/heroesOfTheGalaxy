# Фон главного меню

Основной фон теперь слоистый: `assets/ui/main_menu_layers/` + процедурный
космос (`scripts/menu_space_backdrop.gd`). Эта папка — фолбэк, если слоёв нет.

- Любое количество файлов, любые имена, расширение `.png`/`.jpg`/`.jpeg`.
- Файл подхватывается автоматически — `main_menu.gd:_pick_random_background_texture`.
- Название игры на фолбэк-картинке должно быть нарисовано в кадре: отдельным
  `Label` меню его не дублирует.
- Пустая папка при отсутствии слоёв не ломает меню — плоский фон со звёздами.
