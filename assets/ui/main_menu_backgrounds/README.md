# Фон главного меню

Сюда кладутся картинки фона главного меню (`MainMenu.tscn`).

- Любое количество файлов, любые имена, расширение `.png`/`.jpg`/`.jpeg`.
- Файл подхватывается автоматически — `main_menu.gd:_pick_random_background_texture`
  при входе в меню сканирует папку и берёт случайную картинку, ничего никуда
  не регистрировать не нужно.
- Название игры рисуется прямо на картинке (см. существующий файл) — отдельным
  текстовым `Label` оно не дублируется, поэтому у новых вариантов фона тоже
  должен быть свой логотип в кадре.
- Пустая папка не ломает меню — просто старый плоский фон со звёздами вместо
  картинки.
