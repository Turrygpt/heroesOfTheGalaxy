# Слои фона главного меню

Вырезанные части стартового кадра. Собираются в `menu_space_backdrop.gd`
поверх процедурного космоса (`shaders/menu_space.gdshader`).

| Файл | Что на нём |
|---|---|
| `planet_surface.png` | 2:1 карта поверхности Земли для шейдерной сферы |
| `planet.png` | старый статичный слой планеты, оставлен как запасной референс |
| `ring.png` | орбитальное кольцо |
| `moons.png` | две луны |
| `asteroids.png` | пояс астероидов |
| `logo.png` | название «Герои Галактики» |

Космос, туманности, звёзды и вращающуюся планету рисуют шейдеры.
Папка `../main_menu_backgrounds/` остаётся фолбэком, если слоёв нет.
