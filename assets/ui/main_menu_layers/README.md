# Слои фона главного меню

Вырезанные части стартового кадра. Собираются в `menu_space_backdrop.gd`
поверх процедурного космоса (`shaders/menu_space.gdshader`).

| Файл | Что на нём |
|---|---|
| `planet_surface.png` | 2:1 карта поверхности Земли для шейдерной сферы |
| `planet.png` | старый статичный слой планеты, оставлен как запасной референс |
| `ring.png` | орбитальное кольцо |
| `moons.png` | две луны |
| `asteroids.png` | пояс астероидов |
| `logo.png` | название «Герои Галактики» |

Космос, туманности, звёзды и вращающуюся планету рисуют шейдеры.
Папка `../main_menu_backgrounds/` остаётся фолбэком, если слоёв нет.

## Обновлённое меню

`menu_planet_surface.gdshader` рисует дневную поверхность, кучевые облака,
перистые волокна и города только на ночной суше. Шум погоды задаёт
`shaders/menu_weather.tres`: бесшовная текстура с mipmaps, создаваемая в фоне.
Атмосфера светлеет к солнцу и плавно теряет непрозрачность за краем сферы.

Слои и музыка загружаются через `ResourceLoader.load_threaded_request`.
Кампания загружается после выбора действия; меню показывает проценты и
блокирует повторный запуск. Подготовка новой игры/сохранения выполняется
после загрузки сцены. F8-редактор создаёт интерфейс при первом открытии.

Снимок и замер готовности меню (нужен графический запуск):

```powershell
./Godot_v4.7.1-stable_win64.exe --path . --script res://tools/menu_shot.gd --log-file build/menu_review/capture.log
```

PNG сохраняется в `build/menu_review/menu.png`. `MENU_READY_MS` считает время
до первого кадра с готовыми слоями, отдельно от сохранения PNG и выхода.
Не запускать съёмщик с `--headless`: он явно завершится с ошибкой.

Проверка новой игры, возврата, загрузки, настроек и ленивого F8-редактора:
`tools/test_main_menu.gd`. Запускать с отдельным `APPDATA`, содержащим
`test_profile` в пути; проверка откажется работать с обычным профилем,
поскольку создаёт новую кампанию. Например, задать окружение дочернего
процесса `APPDATA=<проект>/build/menu_review/test_profile`.
