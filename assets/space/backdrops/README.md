# Фоновые декорации боя

Сюда кладутся PNG планет/лун/туманностей для случайного заднего плана
тактического боя (см. `tactical_battle.gd:_pick_backdrop_object`).

- Любое количество файлов, любые имена, расширение `.png`.
- Файл подхватывается автоматически — код при старте боя сканирует папку,
  ничего никуда не регистрировать не нужно.
- Показывается не в каждом бою (см. `BACKDROP_OBJECT_CHANCE`) и не в
  фиксированном месте — случайный угол экрана, случайный масштаб.
- Требования к самому PNG: квадратный кадр, прозрачный фон, объект (сфера
  планеты/луны или туманное облако) по центру кадра. Проверено на 1024×1024.

Промт для генерации — в AGENTS.md, раздел про фон боя.
